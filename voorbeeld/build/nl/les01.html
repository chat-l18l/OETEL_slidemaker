Een test in Python

import serial
port = serial.Serial("/dev/ttyUSB0", 115200, timeout=10)

def wacht_op(tekst):
    regel = port.read_until(tekst.encode())
    return tekst in regel.decode()

assert wacht_op("BOOT OK")

[0] Zo ziet een eenvoudige test eruit.

[1] Eerst openen we de seriële poort.

[2] Dan een hulpfunctie die wacht op een bepaalde tekst.

[3] En de test zelf: we verwachten dat het bord "BOOT OK" meldt.

Baudrate en tijd

\[t_{byte} = \frac{10}{\text{baudrate}}\]

Bij 115200 baud duurt één byte ongeveer \(87\,\mu s\).

[0] Hoe lang duurt het versturen van één byte? Een byte kost tien bits: acht databits, plus een startbit en een stopbit. Tien bits gedeeld door de baudrate geeft bij 115200 baud ongeveer zevenentachtig microseconden.

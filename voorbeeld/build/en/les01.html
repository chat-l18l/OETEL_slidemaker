A test in Python

import serial
port = serial.Serial("/dev/ttyUSB0", 115200, timeout=10)

def wait_for(text):
    line = port.read_until(text.encode())
    return text in line.decode()

assert wait_for("BOOT OK")

[0] This is what a simple test looks like.

[1] First we open the serial port.

[2] Then a helper function that waits for a given text.

[3] And the test itself: we expect the board to report "BOOT OK".

Baud rate and time

\[t_{byte} = \frac{10}{\text{baud rate}}\]

At 115200 baud, one byte takes about \(87\,\mu s\).

[0] How long does sending one byte take? A byte costs ten bits: eight data bits, plus a start bit and a stop bit. Ten bits divided by the baud rate gives about eighty-seven microseconds at one hundred fifteen thousand two hundred baud.
